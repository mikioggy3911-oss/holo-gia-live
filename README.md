# 🎬 Holo Gia Live Stream App

A free live streaming web application where anyone can go live and share their stream with the world.

## ✨ Features

- 🔴 Live video streaming using WebRTC
- 💬 Real-time live chat
- 👁 Live viewer count
- 🔗 Easy share link
- 🔒 Privacy first - videos are NOT saved
- 📱 Mobile responsive
- 🌐 Works on any device with a browser

## 🚀 How to Use

### Going Live
1. Click "Go Live" button
2. Enter your name and stream title
3. Allow camera and microphone permission
4. Start streaming!

### Watching a Stream
1. Click on any live stream from home page
2. Or use a shared link
3. Enter your name
4. Watch and chat!

## 🛠 Tech Stack

- Node.js
- Express.js
- Socket.io
- WebRTC (PeerJS)
- HTML5, CSS3, JavaScript
